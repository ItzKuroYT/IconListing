About this server

Description supplied by the server owner.

Herb Crew is a new factions server with a player-driven economy, custom darkzone & dungeon, bosses, and a store that doesn't sell anything affecting gameplay. You claim land, build cannons, raid other factions, farm bosses in the darkzone and dungeon, and fight over KoTH and outposts. There's a custom auction house, shop, upgradable tools and printer mode. On top of that we have numerous pvp options: duels, hunger games, bounties and coinflips.
